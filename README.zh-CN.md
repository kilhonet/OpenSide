## 概述

网上的很多工作费手不费脑：把几家网店的价格整理成表格、一遍遍填写同样的表单、往博客发文章、在邮箱里翻找需要的邮件……

OpenSide 让您用一行聊天把这些工作交出去。在"需要我帮您做什么？"框里写下想做的事，AI 就会在浏览器中打开网站、阅读页面、点击按钮、输入文字，一直做到完成，然后简短地告诉您结果。收集到的数据可以以 Excel 文件的形式获取。

它不另开浏览器，而是**在您正在使用的 Chrome 或 Edge 中**工作。已经登录的网站无需重新登录；AI 会另开一个标签页工作，这期间您可以继续使用其他标签页。关联 Telegram 后，在外面也能用手机布置任务、接收结果。

AI 部分可以用您已有的 ChatGPT 账户登录，或填入 Claude · OpenAI · Gemini 的 API 密钥。

## 主要功能

- **用聊天完成网页工作** —— 写下想做的事，AI 替您搜索、点击、输入、跳转页面，并告诉您结果。
- **沿用您的浏览器和登录状态** —— 连接您正在使用的 Chrome · Edge 工作，已登录的网站可以直接使用。
- **重复工作自动化** —— 填写表单、从多个页面收集资料这类反复做的工作，可以一次交给它。
- **保存为 Excel** —— 把收集到的资料做成 Excel(.xlsx)文件。需要的话也可以要 CSV。
- **Telegram 远程** —— 用手机上的 Telegram 布置任务、接收回答和文件。无需自己创建机器人。
- **添加文件** —— 可以附上图片 · 文本 · CSV 文件让它阅读，或让它把文件上传到网站。
- **记住看过的内容** —— 开启后会记录您读过的页面和用过的程序，用于回答"昨天看的那篇文章"之类的问题。
- **擅长常用网站** —— NAVER 博客 · Tistory · Blogger 发文、Gmail、Google 文档 · 表格、Notion、Slack、YouTube、NAVER 房产等，用针对各网站的方法处理，更快更准确。
- **多个 AI 账户** —— 登记 ChatGPT(Codex)登录以及 Claude · OpenAI · Gemini API 密钥，在聊天界面中随时切换。
- **深色模式 · 9 种语言** —— 韩语 · 英语 · 日语 · 中文 · 俄语 · 意大利语 · 法语 · 西班牙语 · 阿拉伯语。

## 使用方法

### 快速上手

1. 运行 OpenSide。首次运行时，浏览器(Chrome 或 Edge)会自动打开连接设置页面。
2. 在该页面勾选 **Remote debugging** 复选框。如果页面没有打开，请在浏览器地址栏输入 `chrome://inspect/#remote-debugging`(Edge 为 `edge://inspect/#remote-debugging`)。
3. 浏览器出现连接请求时，点击 **允许**。此设置只需做一次。
4. 接着会打开 **偏好设置** 中的 **账户**。点击 **添加**，选择要用的 AI(例如 **登录 Codex**)，在浏览器打开的登录页面中登录。看到"登录成功"后，关闭该窗口并回到 OpenSide。
5. 在聊天框("需要我帮您做什么？")中写下要做的事，按 **Enter**。例如："告诉我 kilho.net 公告中最新 5 篇文章的标题"
6. AI 工作时，进度会一行行显示。完成后结果以回答的形式出现，进度折叠为一行"用时 N 秒"，点击可再次展开。

### 界面构成

| 元素 | 作用 |
|---|---|
| 聊天标题 | 当前对话的标题。根据第一条消息自动生成，点击即可直接修改(**Enter** 保存 · **Esc** 取消) |
| **最近会话** | 以往对话列表(最近 15 个)。选中即可接着做 |
| **新聊天** | 开始新的对话 |
| **设置** | 打开 **偏好设置** 窗口 |
| 回形针按钮(**添加文件**) | 给消息附加文件。附加的文件显示在输入框下方，可用 × 移除 |
| 输入框 · **发送** | 写下要做的事并发送。工作期间 **发送** 会变为 **停止** |
| **远程控制** 图标 | 开启 / 关闭 Telegram 远程。开启时为绿色 |
| 眼睛图标(**记录**) | 仅在页面记录开启时显示。点击可暂停或恢复记录 |
| 用量圆环 | **登录 Codex** 账户的用量。鼠标悬停可看到剩余量 |
| 账户 · 模型 · 推理级别 | 选择本次对话使用的 AI 账户、模型以及思考的深度 |

### 这种情况怎么办

**把多个网站的信息整理成表格**
像"在三家网店查一下笔记本 A 型号的价格，整理成 Excel"这样，把要收集的内容和想要的形式一起写上。完成后聊天中会出现 **⬇ 下载** 卡片。点击后会询问保存位置(初始为"下载"文件夹)，保存后可用 **打开文件** · **打开文件夹** 直接打开。Excel 文件会原样保留 `007` 或电话号码这类以 0 开头的值。如果需要导入其他程序的文件，请写上"用 CSV" —— 生成的文件不会出现乱码。

**多次填写同一个表单**
像"按这个名单逐一提交申请表"这样布置。AI 会一次填好表单的输入框 · 复选框 · 下拉列表，并确认结果出现后再进行下一个，绝不会重复点击提交按钮。名单在文件里的话，附上文件发送即可。

**只想让它看看，或想让它做到底**
写"比较一下""只写草稿"时，AI 不会执行发送 · 付款 · 删除 · 发布这类无法撤销的操作。反之，像"发出去""下单"这样交代的事，它不会再次询问，会一直点到最后一个按钮。建议在句子里写清楚交给它的范围。

**往博客发文章**
像"用这些内容在 NAVER 博客写一篇文章并发布"这样布置。在 NAVER 博客 · Tistory · Blogger 上，标题 · 正文 · 小标题 · 图片 · 标签都会用适合该网站的方法填入。要放的图片以文件形式附上即可。

**处理邮件 · 文档 · 办公工具**
像"在 Gmail 里找到上周的报价邮件并总结""读一下 Google 表格 B 列的值""在 Notion 会议记录页面添加今天的内容""告诉我 Slack #公告 频道的最新消息"这样布置。它会直接使用浏览器中已登录的账户工作。如果登录了多个 Google 账户，写明是哪个账户，它就会在那个账户中工作。

**在 YouTube · X · LinkedIn 上查找资料**
像"总结这个 YouTube 视频的字幕""整理这个视频评论区的反应""收集 X 上这个话题的最新帖子""在 LinkedIn 上找这家公司的招聘信息"这样布置。

**收集房产房源**
像"把 NAVER 房产上 ○○ 公寓的全租房源整理成 Excel"这样布置，它会把房源列表做成表格。

**查找图片**
像"找 10 张 ○○ 的照片并收集地址"这样布置，它会从图片搜索结果中收集图片地址。

**工作期间使用其他标签页**
AI 只在自己工作的标签页里操作，所以这期间您可以在同一浏览器的其他标签页里继续做自己的事。工作中的标签页即使在后台，也会像在前台一样运行。在同一对话中布置下一个任务时，即使您正在看别的标签页，它也会在原来的标签页继续。新对话从您当前正在看的标签页开始。

**AI 打开的标签页和您的标签页**
AI 只在需要同时查看两个页面时才打开新标签页，并在回答前关闭自己打开的标签页。您自己打开的标签页它不会关闭。想整理自己的标签页时，请直接吩咐，例如"把 kilho.net 的标签页全部关掉"。

**需要验证码 · 银行 App 确认时**
遇到手机验证码、银行 App 确认、文字验证码这类需要人亲自操作的步骤时，AI 会把该标签页调到前台，并用一句话告诉您需要做什么。在浏览器中直接处理，或把验证码写进聊天框发送，AI 就会继续。"我不是机器人"复选框由 AI 自己点击，只有出现选图题时才交给您。注册时如果需要邮件里的验证链接或验证码，只要浏览器中已登录 Gmail，AI 就会打开邮箱去找。

**工作途中补充说明**
AI 工作期间也可以在聊天框中写字发送。这些话会原样传给正在进行的任务。用于改变方向(如"价格用韩元写")或告诉它所问的值。要让它停下，请点击 **停止**。

**让它读取电脑上的文件，或上传到网站**
用回形针按钮附上文件发送，AI 就会读取该文件。图片(png · jpg · gif · webp)会查看内容，文本和 CSV 会读取使用。可以一次附加多个，原始文件不会被改动。像"把附上的照片添加到这个论坛帖子里"这样布置，网站的文件上传窗口也由 AI 处理。

**让它随时读取指定文件夹**
如果每次附加太麻烦，可以在 **偏好设置** → **文件** 的 **AI 可读取的文件夹** 中加入文件夹(**添加文件夹...**)。之后就可以这样布置："用资料文件夹里的客户名单……"。AI 对该文件夹只读不写。请只加入确实需要的文件夹。

**再次找到以前看过的页面**
在 **偏好设置** → **记录** 中开启 **记录我浏览的页面和使用的应用**，它就会记录您读过的页面文字和使用过的程序窗口。之后就可以这样布置："把昨天读的投资文章再总结一下""比较一下刚才看的那几家酒店的优缺点"。记录保留 30 天，含密码输入框的页面不会被记录。不想记录的网站和程序用逗号分隔写上(例如 `bank.com, kakaotalk.exe`)。要暂停记录，点击聊天界面的眼睛图标；要全部清除，点击 **全部删除**。此功能默认关闭。

**查找以前访问过的网站**
像"打开上次去过的那个花店网站"这样布置，它会从浏览器的历史记录中找到并打开。

**在外面用手机布置任务(Telegram)**
1. 在 **偏好设置** → **远程** 中点击 **立即关联**。会显示二维码和关联码，有效期 10 分钟。
2. 用手机相机扫描二维码。Telegram 打开后点击 **开始**。如果电脑上装有 Telegram，也可以点击 **在此电脑上打开**。
3. Telegram 收到已连接的消息即完成。之后在 Telegram 中用文字发送要做的事，电脑上的 OpenSide 就会去做并发回回答。

生成的文件以及"请输入验证码"之类的请求也会发到手机。在 Telegram 中回复验证码，就会传给正在进行的任务。回答较长时，开头部分以消息发送，全文以文件发送。Telegram 只接收文字，请用文字而不是照片发送。电脑上的 OpenSide 必须在运行才能工作，因此使用远程时建议开启 **启动时运行**。要暂时关闭远程，点击聊天界面的 **远程控制** 图标；要彻底断开，点击 **取消关联**。

**使用多个 AI 账户**
在 **偏好设置** → **账户** 中点击 **添加**，会出现可选的类型。

| 类型 | 使用方式 |
|---|---|
| **登录 Codex** | 用 ChatGPT 账户登录 |
| **Claude API 密钥...** · **Gemini API 密钥...** | 填入 API 密钥使用 |
| **OpenAI API 密钥...** | 填入 API 密钥和 **地址 (.../v1)**。更改地址后，也可以使用与 OpenAI 方式相同的其他服务 |

API 密钥账户在保存时会立即获取模型列表进行确认。新对话使用的账户用 **设为默认** 来指定，账户名称双击即可修改。对话中可以在聊天界面下方随时切换账户 · 模型 · 推理级别。推理级别调高会思考得更深，调低则回答得更快。

**查看用量还剩多少**
使用 **登录 Codex** 账户时，聊天界面下方会显示用量圆环。用得越多越满，鼠标悬停可看到各时段的剩余量。快用完时，切换到其他账户即可。

**继续以前的对话**
点击 **最近会话**，会显示最近 15 个对话及其使用时间。选中后接着布置即可。想把标题改得更易辨认，点击顶部的标题。

**自动记住的内容**
AI 每次完成工作后，会把网站的用法、您告诉它的事实等已确认的内容记下来，在之后的对话中使用。同一网站的工作布置得越多，它就越少走弯路。

**关闭窗口后仍保持运行**
点击窗口的 × 不会退出，而是进入通知区域(托盘)。点击托盘图标即可重新显示窗口。要彻底退出，右键点击托盘图标并选择 **退出**。同一菜单中的 **开机时运行** 与 **偏好设置** 中的 **启动时运行** 是同一个设置，开启后会在 Windows 启动时安静地在托盘中启动。OpenSide 只会运行一个，再次运行时会把已打开的窗口调到前台。

**让 OpenSide 窗口始终在前**
想把 OpenSide 放在浏览器旁边边看边用，请在 **偏好设置** → **常规** 中把 **窗口置顶** 设为 **使用**。窗口位置和大小会被记住，下次在同一位置打开。

**在 Chrome 和 Edge 中选哪个工作**
OpenSide 在开启了 **Remote debugging** 的浏览器中工作。两者都开启时，优先使用 Windows 默认浏览器。想让它在另一个浏览器中工作，只在那个浏览器中开启即可。

**重启浏览器后**
需要连接时，OpenSide 会用 **需要连接浏览器** 窗口按顺序告诉您该做什么。照着做之后点击 **连接** 即可。窗口中写的地址点击即可复制，粘贴到地址栏就行。

## 设置

点击 **设置** 按钮会打开 **偏好设置** 窗口。更改会立即生效。

| 选项卡 | 项目 |
|---|---|
| **常规** | **窗口置顶** · **主题**(自动 · 浅色 · 深色) · **语言**(自动或 9 种语言之一) · **启动时运行** |
| **账户** | 添加 · 删除 · 登录 AI 账户 · 指定默认账户 |
| **远程** | 关联 · 取消关联 Telegram |
| **记录** | 开启页面和应用记录 · 暂停 · 不记录的网站和应用 · 全部删除 |
| **文件** | AI 可读取的文件夹 |

**语言** 为 **自动** 时跟随 Windows 显示语言。选择阿拉伯语时界面会变为从右到左。AI 的进度和回答跟随您所写消息的语言。**主题** 为 **自动** 时跟随 Windows 的应用模式(浅色 · 深色)。

## 更新

为了安全并防止杀毒软件误报，OpenSide **不会**自动更新。启动时会检查是否有新版本并提示；选择获取后，会打开下载页面并关闭程序。新版本经内部验证后手动发布，并在 [OpenSide 页面](https://kilho.net/openside)公告。请参阅[更新政策说明](https://en.kilho.net/archives/notice/2940)。
